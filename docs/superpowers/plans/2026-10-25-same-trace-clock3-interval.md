# Same-trace clock-3 interval implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in, exact decimal-string diagnostic for two named recorded instants in the supported same builtin clock-3 domain, without native or metric authority.

**Architecture:** Add an opt-in V8 raw-drop inventory to the existing owned reader/ordered engine, observing supported headers before reset precedence. A separate interval module calls that relative V8 entry once and applies the fixed narrow contract. The interval module has only a private package export; genuine worker dispatch remains V6, V6/V7 outputs stay identical, and no new capture-runtime descendant module is introduced. Caller-supplied V7/V8 JSON is never admitted.

**Tech Stack:** Node >=24, npm >=11 locked workspaces, TypeScript, existing protobuf fixture helpers, Vitest 5, Node fs/crypto/util and BigInt. This repository is npm/Vitest/tsc based; do not use the Nx instructions from an unrelated workspace.
