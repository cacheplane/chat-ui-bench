# Disabled virtualizer attribution unit

This unit has no normal application import or build wiring. It has not observed
any hosted run. It provides no qualification, native GO, performance, FPS,
continuous stability, or scroll-settlement authority. A recorded delegate return
means only that the original call returned.

The test-support transform accepts only the complete pinned Tanstack virtual-core
3.19.4 ESM module (54,156 bytes, SHA256
`06f0d457a913752786a32f3f16dff0c5a9c5a8c4877665c31a2e74598db13c09`).
Tests authenticate its two executable relative imports and compare fresh actual
original/transformed module copies. The insertion receipt reverses to the exact
original bytes; arbitrary added insertions are refused. Observer imports must be
canonical absolute file URLs. No installed dependency is modified.

Tuple ABI v1 is documented at `apps/copilotkit/src/scroll-cause-diagnostic.ts`.
Each row has exactly 32 finite numeric/null atoms. Keys and object identities are
opaque bounded tokens; no keys, content, error payload, clock or DOM read is
published. Synchronous scopes identify dynamic resize-adjustment call extent;
requests outside those scopes have a null cause. Original exceptions preserve
identity and retire scopes while marking coverage incomplete. Open scopes also
make a snapshot incomplete. This does not attribute a future or deferred write.
`complete` describes only this ledger's storage and scope state. It does not
prove that hooks were installed, ownership matched, or an interval was covered;
an empty complete ledger does not prove that no adjustment occurred.

Defaults are 1,024 records, four instances and four delegate receivers, 1,024
primitive keys, depth eight for each per-instance resize/cause stack, and 1 MiB.
Primitive string keys are limited to 256 code units; bigint keys to the safe
integer magnitude. The 32-atom schema enforces at most 26 ASCII bytes per numeric
encoding: a row is at most 865 bytes (below 896), and
`1024 * 865 + 1023 + 4096 = 890879 < 1048576`, including row separators.
A 4 KiB header reservation plus exact
row lengths/commas is charged before retention, with a final whole-snapshot byte
check. Reduced limits are supported; the byte limit must be at least 4 KiB.
Overflow or invalid data latches a fault, stops retention and increments a bounded
fault-occurrence count. That count includes internal refusals and is not a count
of omitted records; `omittedRecords` is explicitly unavailable. There is no ring
buffer or selective truncation. Snapshots
copy owned data and never promote authority.

Hosted build transformation, emitted-source proof, host markers, publication and
diagnostic workflow integration require a separate review. Existing runtime
guards, inventories, workflow inputs and qualification policies are unchanged.
